# Logo MRI Pro

Nové logo aplikace MRI Pro podle loga MRI Servis (značka mRI, pod ní PRO se stříškami z původního loga).
Barvy: tmavá #231F20, oranžová #F89C1D, světlá oranžová stříšek #F9D581, pozadí ikony #1C1F22.

Vše najednou: `logo-mri-pro.zip`.

| Soubor | Použití |
|---|---|
| `mri-pro-logo.svg` | logo na světlé pozadí, vektor (libovolná velikost) |
| `mri-pro-logo-bile.svg` | logo na tmavé pozadí, vektor |
| `mri-pro-logo-2000.png`, `mri-pro-logo-bile-2000.png` | totéž jako PNG s průhledným pozadím, šířka 2000 px |
| `mri-pro-ikona.svg`, `mri-pro-ikona-1024.png` | ikona aplikace (tmavý čtverec se zaoblenými rohy) |
| `favicons/` | stejné názvy jako dnes v `mripro.cz/assets/favicons/`: android-chrome 192 a 512, apple-touch-icon 180, favicon 16 a 32, favicon.ico, safari-pinned-tab.svg |
