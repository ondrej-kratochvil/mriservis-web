# Logo MRI Servis

Nové logo firmy MRI Servis - průmyslová automatizace s.r.o. (dodal Marek Drgáč 31. 10. 2026).
Barvy: tmavá #231F20, oranžová #F89C1D.

Vše najednou: `logo-mri-servis.zip`.

| Soubor | Použití |
|---|---|
| `mri-servis-logo.svg`, `mri-servis-logo-bile.svg` | logo bez sloganu na světlé a tmavé pozadí, vektor |
| `mri-servis-logo-slogan.svg`, `mri-servis-logo-slogan-bile.svg` | logo se sloganem Průmyslová automatizace, vektor |
| `*-2000.png` | totéž jako PNG s průhledným pozadím, šířka 2000 px |
| `originaly/` | soubory tak, jak je Marek dodal (bílé pozadí) |

SVG jsou převedené z dodaných obrázků (2892 px), ne z původního vektoru od grafika. Pro tisk je lepší vyžádat vektor od autora loga.
